# exercicio25 Contagem de 1 a 10

## Descrição

O programa utiliza a estrutura de repetição `while` para realizar uma contagem de 1 até 10.

A cada repetição, o valor atual é exibido e incrementado em 1.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

Este programa não possui entrada de dados.

## Saída

O programa imprime os números de 1 até 10, cada um em uma linha.
